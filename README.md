# Practical-4: Android Alarm Application Using Service and BroadcastReceiver

## Aim

To create an **Android Alarm Application** using **Service** and **BroadcastReceiver** that allows the user to select a time and trigger an alarm using Android's `AlarmManager`.

## Tools Required

- Android Studio
- Android SDK
- Kotlin
- Android Emulator or Android device

## Practical Objectives

### 4.1 Create MainActivity

Create `MainActivity` according to the given UI design.

The Activity should provide a user interface for:

- Displaying the current time
- Selecting an alarm time
- Setting an alarm
- Starting/stopping the alarm service
- Displaying the selected alarm information

The UI can be designed using:

- `ConstraintLayout`
- `MaterialCardView`
- `TextClock`
- Buttons
- `TimePickerDialog`

### 4.2 Create AlarmBroadcastReceiver

Create an `AlarmBroadcastReceiver` class by extending `BroadcastReceiver`.

The BroadcastReceiver receives the broadcast when the scheduled alarm time is reached.

Example structure:

```kotlin
class AlarmBroadcastReceiver : BroadcastReceiver() {

    override fun onReceive(
        context: Context?,
        intent: Intent?
    ) {
        // Handle alarm broadcast
    }
}
```

The receiver can start the `AlarmService` when the alarm is triggered.

### 4.3 Create AlarmService

Create an `AlarmService` class by extending Android's `Service` class.

The Service is responsible for performing the alarm operation, such as playing an alarm sound using `MediaPlayer`.

Example structure:

```kotlin
class AlarmService : Service() {

    private var mediaPlayer: MediaPlayer? = null

    override fun onCreate() {
        super.onCreate()

        // Initialize MediaPlayer
    }

    override fun onDestroy() {
        mediaPlayer?.stop()
        mediaPlayer?.release()
        mediaPlayer = null

        super.onDestroy()
    }

    override fun onBind(intent: Intent?): IBinder? {
        return null
    }
}
```

## 4.4 Schedule Exact Alarm Permission

Add the following permission to the `AndroidManifest.xml`:

```xml
<uses-permission
    android:name="android.permission.SCHEDULE_EXACT_ALARM" />
```

Exact alarm permission is used when the application needs to schedule an alarm at a precise time.

Depending on the Android version and target SDK, additional alarm permission handling may be required.

## 4.5 BroadcastReceiver

A **BroadcastReceiver** is an Android application component that allows an application to receive broadcast messages from the Android system or other applications.

In this practical, the `AlarmBroadcastReceiver` receives the broadcast generated by `AlarmManager` when the scheduled alarm time is reached.

### Basic Flow

```text
User selects alarm time
        ↓
MainActivity
        ↓
AlarmManager
        ↓
PendingIntent
        ↓
AlarmBroadcastReceiver
        ↓
AlarmService
        ↓
MediaPlayer
        ↓
Alarm Sound
```

## 4.6 Service

A **Service** is an Android component used to perform operations that can continue without a user interface.

In this practical, the Service is used to handle the alarm sound using `MediaPlayer`.

The Service can be:

- Started using `startService()`
- Stopped using `stopService()`

## 4.7 TextClock

`TextClock` is an Android UI component that displays the current time in a specified format.

Example:

```xml
<TextClock
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:format12Hour="hh:mm:ss a" />
```

It can be used to display a live digital clock in the application.

## 4.8 TimePickerDialog

`TimePickerDialog` provides a dialog that allows the user to select an hour and minute.

Example:

```kotlin
val timePickerDialog = TimePickerDialog(
    this,
    { _, hour, minute ->
        // Selected time
    },
    hour,
    minute,
    false
)

timePickerDialog.show()
```

The selected hour and minute are then used to schedule the alarm.

## 4.9 Calendar Class

The `Calendar` class can be used to create and manipulate date and time values.

It can be used to set:

- Year
- Month
- Day
- Hour
- Minute
- Second

Example:

```kotlin
val alarmCalendar = Calendar.getInstance()

alarmCalendar.set(
    Calendar.HOUR_OF_DAY,
    hour
)

alarmCalendar.set(
    Calendar.MINUTE,
    minute
)
```

The resulting time can be passed to `AlarmManager`.

## 4.10 SimpleDateFormat

`SimpleDateFormat` is used to format date and time into a readable string.

Example:

```kotlin
val format = SimpleDateFormat(
    "hh:mm:ss a",
    Locale.getDefault()
)

val time = format.format(alarmCalendar.time)
```

It can be used to display the selected alarm time to the user.

## 4.11 AlarmManager

`AlarmManager` is an Android system service used to schedule operations to occur at a specific time.

Example:

```kotlin
val alarmManager =
    getSystemService(Context.ALARM_SERVICE) as AlarmManager
```

An alarm can then be scheduled using a `PendingIntent`.

## 4.12 getSystemService()

`getSystemService()` is used to access Android system services.

Example:

```kotlin
val alarmManager =
    getSystemService(Context.ALARM_SERVICE) as AlarmManager
```

It can provide access to services such as:

- `AlarmManager`
- `NotificationManager`
- `PowerManager`
- Other Android system services

## 4.13 PendingIntent

A `PendingIntent` gives another application or the Android system permission to execute a predefined Intent on behalf of the application at a later time.

In this practical, `PendingIntent` is used with `AlarmManager` to trigger the `AlarmBroadcastReceiver`.

Example concept:

```text
AlarmManager
     ↓
PendingIntent
     ↓
BroadcastReceiver
```

## 4.14 sendBroadcast()

`sendBroadcast()` is used to send a broadcast Intent to registered BroadcastReceivers.

Example:

```kotlin
sendBroadcast(intent)
```

It can be used to communicate an event from one component to another.

## 4.15 Intent.putStringExtra()

`putStringExtra()` is used to attach string data to an Intent.

Example:

```kotlin
intent.putStringExtra(
    "alarmTime",
    "07:30 AM"
)
```

The data can later be retrieved using `getStringExtra()`.

## 4.16 Intent.getStringExtra()

`getStringExtra()` retrieves a String value previously stored in an Intent using `putStringExtra()`.

Example:

```kotlin
val alarmTime =
    intent.getStringExtra("alarmTime")
```

This can be used to pass information such as the selected alarm time between Android components.

## 4.17 MediaPlayer

`MediaPlayer` is used to play audio and video files.

For this practical, it can be used to play the alarm sound when the `AlarmService` starts.

Example:

```kotlin
mediaPlayer = MediaPlayer.create(
    this,
    R.raw.alarm
)

mediaPlayer?.start()
```

The `MediaPlayer` should be properly released when the Service is stopped.

## 4.18 startService()

`startService()` is used to start a Service.

Example:

```kotlin
val intent = Intent(this, AlarmService::class.java)
startService(intent)
```

The Service can then perform the required alarm operation.

## 4.19 stopService()

`stopService()` is used to stop a running Service.

Example:

```kotlin
val intent = Intent(this, AlarmService::class.java)
stopService(intent)
```

In this practical, it can be used to stop the alarm sound.

## 4.20 MaterialCardView

`MaterialCardView` is a Material Design UI component used to display content inside a card.

It can be used to create an attractive alarm interface containing:

- Alarm time
- Clock
- Alarm controls
- Other information

Common properties include:

```xml
app:cardCornerRadius="..."
app:cardElevation="..."
```
